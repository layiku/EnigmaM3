# 恩尼格玛 M3 —— 交互式 3D 模拟器

`enigma_m3.html` 是一个单文件、在浏览器中运行的二战德军 **Enigma M3** 密码机 3D 模拟。模型完全由 Three.js 程序化构建（无外部 3D 模型），使用 GSAP 动画，并由符合真实机械逻辑的 M3 加密引擎驱动。

## 功能

**加密引擎**
- 转子 **I–VIII**，真实接线与缺口：I=Q, II=E, III=V, IV=J, V=Z, VI/VII/VIII=Z+M（双缺口）。
- 反射器 **UKW-B** 与 **UKW-C**。
- 每个转子的字母环设置（Ringstellung）与初始位置；还原 **双步进** 反常机制。
- 插线板（Steckerbrett）最多 **13 对**。
- `encryptChar()` 返回完整信号路径（插线板 → 转子 → 反射器 → 转子 → 插线板 → 灯泡）。

**3D 模型与视觉**
- 程序化胡桃木外壳、带观察窗的黑色皱纹烤漆顶盖、黄铜部件、羊皮纸字母环。
- 26 个按键、26 个带磨砂字母窗的灯泡（点亮时字母发光）、3 个转子 + 反射器 + 入口轮；每个转子含 26 根内部铜线、触点与棘轮。
- 转子分为字母环（带缺口片）与接线芯；改变字母环设置时，接线芯相对字母环转动。
- 内部机构：底盘、步进棘爪与杠杆、灯座、按键触点、4.5V 电池盒与线束。
- **一键分解图**：顶盖、木盒、键盘、灯板、插线板、转子与内部结构分层展开。
- **信号路径发光**：每次按键时，激活的转子/反射器铜线、插线板跳线以及内部线束同时发光。

**插线板交互**
- 26 个黄铜双孔插槽与 13 根带自然下垂的贝塞尔曲线电缆。
- 点击空插槽生成插头并拖到另一插槽；**磁吸吸附**（琥珀色导引环与咔哒声）。
- 拖动已插入插头可改插；单击即拔出整根线。
- 按钮：**一键插满 13 对**（依次飞入）、**历史预设 10 对**（`AV BS CG DL FU HZ IN KM OW RX`，默认）、**全部拔出**。
- **聚焦插线板** 视角（锁定旋转）与 **总览视角**。

**操作**
- 物理键盘 A–Z 或点击 3D 按键；点击转子上半部/下半部向前/向后拨动。
- **自动敲击**：以 350 ms/字符输入粘贴文本（文本框中的变音字母自动转写为 AE/OE/UE/SS）。
- 双纸带（输入/输出），按 5 字母一组打印。
- **复位转子**：完全复位为 I-II-III、字母环 AAA、初始位 AAA、UKW-B。
- Web Audio 合成音效：按键声、转子棘轮声、插头吸附/插入声。

**界面**
- 语言 **EN / 中文 / DE**（默认 EN，会记住选择）。EN 与中文使用 QWERTY 布局；DE 使用真实恩尼格玛布局 **QWERTZUIO / ASDFGHJK / PYXCVBNML**。切换 *进入* DE 时会清空纸带。
- **FIX 模式**（默认开启，会记住）：无论窗口大小，模型保持 1920×1080 渲染时的屏幕尺寸，背景铺满整个窗口。
- 可拖动的转子读数窗口，带黄铜 **平移面板**（上/下/左/右平移、沿地面前进/后退、复位视角；按住可连续移动）。
- **Shift+V** 将当前相机视角以 JSON 复制到剪贴板。

## 运行方法

用现代桌面浏览器（Chrome、Edge、Firefox、Safari）直接打开 `enigma_m3.html`。需要联网：Three.js r160（通过 `unpkg.com`，ES 模块 import map）与 GSAP 3.12（通过 `cdn.jsdelivr.net`）从 CDN 加载。无需构建或服务器。

## 操作说明

| 动作 | 方式 |
|---|---|
| 加密一个字母 | 键盘 A–Z，或点击 3D 按键 |
| 拨动转子 | 点击转子上半部（前进）/ 下半部（后退），或使用初始位下拉框 |
| 转子顺序 / 字母环 / 反射器 | 面板下拉框（选择已在其他位置使用的转子会自动互换） |
| 连接插头 | 点击空插槽，拖到另一插槽 |
| 改插 / 拔出 | 拖动已插入插头 / 单击它 |
| 旋转 / 缩放相机 | 鼠标拖动 / 滚轮 |
| 平移相机 | 转子读数下方的平移面板 |
| 复制相机视角 | Shift+V |
| 移动读数窗口 | 拖动其边框；双击复位位置 |

## 架构

| 类 | 职责 |
|---|---|
| `EnigmaEngine` | 纯密码逻辑：转子、缺口、步进、字母环、反射器、插线板、信号路径输出 |
| `Enigma3DScene` | 程序化 3D 模型、材质、灯光、分解图、发光效果、按需渲染循环 |
| `PlugboardInteraction` | 13 根跳线、拖拽、磁吸吸附、电缆曲线、插头动画 |
| `InteractionController` | 控制面板、多语言、键盘/指针输入、自动敲击、纸带、相机预设、平移面板 |

## 验证向量

- 转子 I-II-III、UKW-B、字母环 AAA、初始位 AAA、无插线：`AAAAA` → `BDZGO`。
- 双步进：初始位 ADU → ADV、AEW、BFX。
- 自反性：以相同设置再次加密密文可还原明文。

## 历史说明

- 机器只有 26 个字母：操作员将 Ä/Ö/Ü/ß 写作 AE/OE/UE/SS，用 X 表示句号，数字通常用单词拼出；海军有时把 CH 写作 Q。
- 转子 I–V 由陆军和空军使用（5 选 3）；VI–VIII 仅海军使用。
- 按键、灯泡与插线板铭牌使用与原机一致的普通无衬线大写字母。

## 性能说明

- 静态几何体按材质合并；字母环与铭牌使用纹理图集；铜线发光使用临时叠加网格。
- 仅在有变化（相机、动画、输入）时渲染，标签页隐藏时暂停；像素比上限 1.5；小部件不投射阴影。
